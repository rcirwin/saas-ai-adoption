## Themes to add to MEMORY for future runs

1. **Legal vertical is HEAVILY CONSOLIDATED in 2024-2026** — ProfitSolv (Lightyear), 8am/AffiniPay, Paradigm, Mitratech, Stretto, ASG, Filevine portfolio. Cross-check every candidate against `lawnext.com` ownership scorecard before adding.
2. **Australian allied-health practice mgmt is a strong, founder-led, bootstrapped niche** — Cliniko, Halaxy, CorePlus, Nookal, Zanda. All founder-led, none PE-rolled-up. Good cluster to keep mining.
3. **Healthcare bootstrapped is concentrated in specialty/integrative practices** — CharmHealth (small clinics), OptiMantra (now acquired), Pabau (medical spas), CorePlus (allied), Carepatron. Mass-market EHR (Epic, Cerner, athenahealth) is unreachable; specialty is the only ICP-relevant entry.
4. **Open-source accounting (Bigcapital, Akaunting)** is an under-explored cluster — founders are typically solo-developer-CEOs without sales teams, ARR is opaque but engagement is real (high GitHub star counts). Probably useful only when they hit ~$500K ARR commercial offering on top of OSS.
5. **R&D tax credit SaaS** (TaxRobot) is a productive niche for bootstrapped fit — narrowly scoped, high ACV, often one-founder shops.
6. **GetLatka indexes for "X-software" categories** are by far the highest-signal route for finding bootstrapped ICP-fit companies, much better than directory pages.
