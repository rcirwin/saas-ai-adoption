## Environment

`python3 scripts/sheet.py` failed on first call with
`ModuleNotFoundError: No module named '_cffi_backend'` followed by a `pyo3_runtime.PanicException`.
Root cause: the default interpreter is python3.11 (`/usr/local/bin/python3`), the google-auth stack
lives in `/usr/local/lib/python3.11/dist-packages`, but the only `cryptography` on the path was the
Debian system package in `/usr/lib/python3/dist-packages` built against **cpython-3.12**
(`_cffi_backend.cpython-312-*.so`). Fix:

```
pip install --force-reinstall --target=/usr/local/lib/python3.11/dist-packages cffi cryptography pycparser
```

This is a different failure from the July run's `pip3 install cffi` — that one no longer suffices
because the system `cryptography` shadows any 3.11-compatible build unless a 3.11 copy is placed in
`/usr/local/lib/python3.11/dist-packages`. Note `/usr/bin/python3.12` has a working `cryptography`
but is missing `google-api-python-client`, so it is not a workaround.
