## Key learnings for memory

1. **Indie podcast-creator tools (Alitu, Podpage, Captivate, Buzzsprout) form a tight ICP cluster.** Most are bootstrapped, $1-5M ARR, founder-led, niche under threat from AI-native creator tools.
2. **WordPress-adjacent paid SaaS (WP Fusion, LifterLMS) is a clean Profile A vein.** Founders typically engineers since 2014-2015, small teams (~10), $500K-$2M ARR.
3. **EU bootstrapped clusters** in Belgium (Salesflare, Customerly, Tally), Estonia (Featurebase), Netherlands (Booqable, ConvertCalculator), Germany (Smoobu, Pirsch, Passbase, Affilimate), Spain (Heepsy, Mailsuite/Mailtrack), Italy/Ireland (Customerly).
4. **Vertical SaaS family businesses** (Akada Software since 1994, BNTouch since 2004) are a high-fit segment under-explored.
5. **GetLatka has fresh 2024-2025 data on ARR + team size + funding** — by far the most efficient source for bootstrap verification.
6. **DQ rule #6 (>$10M raised + <$5M ARR)** triggered repeatedly on Series A SaaS that "feel bootstrapped" but have meaningful runway already (e.g. Loops.so, Vimcal, Tonkean).
7. **Multi-product holding-parent DQ** caught Awesome Motive (PushEngage), StellarWP/Liquid Web (LearnDash, RCP), SaaS Labs (JustCall, Helpwise), Togetherwork (PetExec, Gingr), EverCommerce (Joist).
8. **Slug convention reinforced**: bare name without TLD when name is unambiguous (`papermark`, `customerly`); kebab for multi-word (`lead-onion`, `cognito-forms`, `lucky-orange`).
9. **`$` in shell args** (notes containing `$1M`, `$5K`, etc.) gets eaten — always do append then update with single-quoted notes.
10. **Two accidental duplicates created** (wp-fusion-recheck, marker-io-2 — same company different id). Marked DELETED-DUP-DO-NOT-USE. Going forward: check dedup cache against company name not just id.
