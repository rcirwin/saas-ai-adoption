## Key learnings (see MEMORY.md)
- GetLatka by-industry indexes return clean ARR+employee+funding for under-$5M bootstrapped; the courier-software index alone surfaced 8 sub-$5M no-funding candidates (best single yield this run).
- Courier/freight/logistics-ops is a surprisingly clean bootstrapped vein (Dispatch Science, Cario, CourierManager) vs. trades field-service which stayed a graveyard.
- Niche back-office SaaS (HOA, self-storage, janitorial inspection, scrap-yard, pharmacy, dental-lab, museum CMS) survives bootstrapped far better than dispatch-heavy trades (pool/towing/auto repair mostly acquired/PE).
- "GetLatka no-funding listed" can be stale — always run `"<name>" acquired`/`funding` before adding (caught Cordic $14M+CabFusion, QuikStor control-change, OpenCampground, Pocomos $9M-vs-$1.8M conflict).
