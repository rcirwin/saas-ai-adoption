# 2026-05-19 batch-1 run (20 prospects)

Drafted batch 1 of several for ~177 researched prospects missing `outreach_linkedin_draft` / `outreach_email_draft` Sheet columns. Picked top 20 by fit score (excluding the 7 dossier-flagged fit-2 prospects already handled on 2026-05-14).

## Key findings

- **Prior draft files exist but Sheet columns are empty — the 2026-05-15 runs never wrote to the Sheet.** 17 of 20 prospects had email draft files and 14 had connect draft files from 2026-05-15, but every `outreach_linkedin_draft`/`outreach_email_draft` column was blank. The 2026-05-15 runs hit the credentials-missing fallback path and only produced draft files, never Sheet writes. **How to apply:** when the task is "fill empty Sheet draft columns," always cross-check `agents/outreach-drafts/` for existing files first. Reuse clean existing drafts rather than regenerating; only draft the genuinely missing channels.

- **All 14 existing 2026-05-15 linkedin-connect drafts contained em dashes (hard-rule violation).** The 2026-05-15 email drafts were all clean, but every connect draft from that date used an em dash. Re-drafted all 15 (incl. orderease) as fresh 2026-05-19 versions with `supersedes:` frontmatter. **How to apply:** never trust a prior draft file is rule-compliant. Run the em/en/hyphen-space + banned-word self-check on every file before writing it to the Sheet, even files written by an earlier run of this same agent.

- **`sheet.py update` syntax is `update <tab> --where col=val --set col=val ...`** — NOT `update <tab> id=val col=val`. The bare-arg form fails with "unexpected arg 'id=...'". The `append` command uses bare `col=val` args; `update` does not. Lost one full pass to this. **How to apply:** always use `--where` and `--set` for updates.

- **Email subject extraction:** email draft bodies start with a `Subject: ...` first line. Split it off into `outreach_email_subject` and write the rest to `outreach_email_draft`. The `outreach_log.message_text` keeps the full body incl. subject.

- **setmore + memberspace still report "updated 2 row(s)"** — duplicate prospect rows persist (also seen 2026-05-15). Future dedupe maintenance pass needed.

## End state

38 outreach_log rows appended (20 connect + 18 email; paperless-pipeline and sweft have no contact_email so connect-only). 20 prospect rows updated. All Sheet writes succeeded with 2s pacing, zero quota retries needed. 157 researched-without-drafts prospects remain for later batches.
