## Heuristics Confirmed

- **Parallel-channel touch breaks the disposition-block (2026-05-27)**: when a prospect is past `follow_up_cadence_days` AND has at least one channel previously `sent` AND has a different channel still untouched (contact data present, never sent), drafting on the UNTOUCHED channel is legitimate first-touch-on-that-channel, not a disposition-blocked second-touch. The agent doesn't need `response_status` from the sent channel to make this call; it just needs to verify the other channel has never gone out. Built the filter `(days_since_last >= cadence) AND (any sent row exists) AND (contact data for untouched channel exists)` against the log + prospects join — found 22 qualified prospects in a queue where pure same-channel second-touch was 82-prospect disposition-blocked. **Why this matters**: without this filter, every past-cadence prospect with a sent row stays no-op until Ryan backfills outcomes, which has been the bottleneck for ~10 weeks. With this filter, parallel-channel runs unblock 22 of 104 past-cadence prospects without any disposition data. **How to apply**: on past-cadence days, always check whether the prospect has an untouched channel before declaring disposition-block. Cross-channel hooks must be distinct from the prior sent channel's hook (frontmatter `prior_touch:` + `hook_distinct_from_prior: yes`).

- **"leverage" as noun is also banned by the agent's self-check (2026-05-15 batch C)**: voice-guide.md says "leverage (as verb)" is banned, but the step 6e self-check uses `word.lower() not in body.lower()` which catches noun usage too. Five drafts in the 23-prospect email batch C (`referral-rock`, `userlist`, `zenmaid`, `coreplus`, `everhour`) needed a second pass to swap noun "leverage" for `winning move`, `internal-ops compounding`, `compounding question`, `highest-impact one`, `operator-side layer`. **Why**: agent definition's hard rules (step 6e) override voice-guide nuance. Self-check is intentionally strict. **How to apply**: don't use "leverage" in any form. Always reach for `compounding`, `the bet that compounds`, `where it earns its place`, `the right two bets`. Also avoid "unlock", "unlocking" — flagged separately as banned.

- **Paced sheet writes work cleanly with 4 parallel agents (2026-05-15 batch C)**: 2-second sleep between each `sheet.py` write (4s per prospect with append + update) kept all 23×2 writes under the 60/min API quota when 4 other email-drafting agents were running in parallel on different batches. Zero rate-limit errors. **Why**: 60/min quota is per-user, so 5 parallel agents share it — naive parallel writes would burst over. **How to apply**: on multi-agent days, pace writes at 2s/call minimum. Don't rely on individual per-prospect retries; the pacing is the cheaper solution.

## Anti-Patterns to Avoid

- Generic hooks like "your product looks interesting" — always cite a specific launch, post, or positioning statement from research.

- Soft sell language ("would love to chat", "let me know if interested") — use Ryan's direct-but-warm voice: "No pitch, just curious how you're thinking about it."
- Starting with "I" — start with "Hey <name>" and put the hook (specific observation) in line 2.
