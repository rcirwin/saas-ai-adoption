# GetLatka country pages with cap filters

**URL pattern:** `https://getlatka.com/companies/countries/{country}?cap={small|mid|xlarge}`

**What's visible without auth:** Top 10 companies per cap tier with:
- ARR (fresh — 2024-2025 numbers)
- Employee count
- One-line business description
- Website

**What's paywalled:** Funding rounds, growth data, founder names, deeper team size detail.

**Highest-yield countries (verified 2026-05-28):**
- South Africa — small AND mid both productive. Genuine bootstrapped ICP-fit veins: Callbi, PropWorx, mySHEQ, Brandbook, Grapevine, HTI, Swordfish, M2North.
- Argentina mid-cap — FindThatLead, Dux Software, Wispro.
- Chile small + mid — Onesta, Videsk, Kobra, Parkeate, Cardda, Regcheq, RendaloMaq, Encuadrado, Instacrops, Geti.
- Mexico mid — Polo, Holacasa, Covela, Pulppo, Clupp, Shuttle Central, Levo, Befective.
- Colombia mid — HippoBuild, OhmyFi, Eduvolucion, Trebol, Vecindario, Ubidots, B2Chat.
- Peru — Bsale, MindQube, Laus.
- Uruguay — Vexels, Flokzu, Bankingly, Feng Office.

**Lower-yield countries (paywall hits earlier):**
- Israel — only ~10 small-cap visible; bigger names dominate. PractiTest, Accessiblizer were the only clean fits.
- Korea — same pattern. CallGate, Send Anywhere were the clean ones.
- Japan — top 10 only, all over ICP.
- Brazil — top 10 only, all over ICP (CloudWalk, Loggi, QuintoAndar).

**Why:** Use these BEFORE Crunchbase/Tracxn for under-served-geo sourcing. The 10-company-per-cap snapshot is enough to fill a 50-prospect run if you hit ~8 countries.

**How to apply:** When running for LATAM/MENA/SA, start with `?cap=small` and `?cap=mid` per country. Each pair yields 10-20 candidates; expect 60-80% to be ICP fits after AI-native + B2C + acquired filtering. Verify founder/contact via separate name searches only after appending.
