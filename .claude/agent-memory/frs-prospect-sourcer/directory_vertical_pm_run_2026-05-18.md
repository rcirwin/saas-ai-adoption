- **Manufacturing ERP for SMBs is low-yield** — consolidated or funded. MRPeasy fit; Cetec crossed the cap; Digit is funded + AI-native. ~1 fit per deep search.
- **Nonprofit ops is heavily rolled up** — Bloomerang (serial acquirer), Keela (ASG/Aplos consolidator). Little Green Light is a rare surviving independent. Low yield.
- **Veterinary practice management — drop from regular sampling.** Every candidate either over cap (Shepherd $8.2M) or heavily VC-backed (Digitail $37M raised). Fully consolidated/funded.
