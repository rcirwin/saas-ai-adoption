50 net-new EdTech prospects added 2026-05-28 across 11 sub-categories. Hard-floor 50 hit exactly. See `agents/sourcing-runs/2026-05-28-edtech-50.md`.

**Why:** Caller assigned EdTech territory exclusively while 9 sibling sourcer agents covered other categories in parallel. Hard 50 floor required (not the usual 30 cap).

**How to apply:** Future EdTech-focused runs should prioritize:

1. **GetLatka direct search** is the fastest verification source. Pattern: `site:getlatka.com bootstrapped [category] revenue 2024 founder small employees` — returns ARR + emp + funding + founder in one shot.
2. **Indian + Brazilian + EU EdTech** is under-mined for bootstrapped fits: BrainCert, Mykademy, Learnyst, Abara, PhishX, Atiom, Adeption, Culcha, Whale, LanguaTalk all ICP-clean.
3. **Library SaaS** (LibraryWorld, Surpass) is sleepy bootstrapped vein — 30+ year independents.
4. **K-12 SIS for small private/microschools** has real indies (Schoolable, QuickSchools, SchoolCues, DreamClass, Sycamore, BigSIS, Edsby) but most enterprise players consolidated.
5. **Acquisition trap heaviest in K-12**: Pike13/Teachworks/Sawyer (Jonas Software/DaySmart), Pear Deck/Schoology (PowerSchool), Edmodo, AccessAlly (Caseproof), SchoolMint (PowerSchool affiliated), TADS (Community Brands), Schoolytics (Newsela Jan 2026). Always run "[name] acquired 2024" before adding.
6. **Corporate L&D consolidated above ICP**: TalentLMS, Schoox, Easygenerator, LRN, WorkRamp, Skilljar all out of range. Fits sit in $1-5M ARR niche players.
7. **Multi-product holding parent rule** worth applying: Port 443 (TutorBird/MyMusicStaff/AthletaDesk) survives — 16 emp + $0 raised + small total ARR. But TADS rolled up into Community Brands; ePath Learning rolled into Absorb. Always check parent.
