**Why this matters / how to apply (verticals fresh from the earlier-today vertical-saas run which mined print/jewelry/consignment/childcare/equine/chiro/catering/gun/device-repair/church/brewery/fitness):**

- **GetLatka by-industry indexes (`getlatka.com/companies/industries/i-<vertical>-software`) are the single highest-yield source for sub-$5M bootstrapped vertical SaaS.** They return ARR + employee + funding + founding-year for the top ~10 per category without paywall. The `i-courier-software` index alone gave 8 sub-$5M no-funding candidates in one fetch (best yield of the run). Many index URLs 404 (try the canonical `-software` slug; some are `-management-software` / `-practice-management-software`). Fitness/agriculture/property-mgmt/veterinary indexes only show top-10 which were all over-cap.

- **Courier/freight/logistics-ops is a clean bootstrapped vein** — Dispatch Science (Montreal, $4M, 2011), Cario (AU, $2M, 2018), CourierManager (Romania, Radu Floricica, 10yr). Contrast with dispatch-heavy *trades* field-service (pool/towing/auto-repair/HVAC) which stayed a graveyard (Molo→Storable, PoolTrackr→Fluidra, Cordic→CabFusion, most others VC/PE). Mine courier/freight before trades next time.

- **Niche back-office SaaS survives bootstrapped far better than trades dispatch.** Clean fits clustered in: self-storage (StoragePug $2.4M, StoRegister $770K), HOA (HOALife $3.4M w/ tiny $300K Calm-Company seed = still OK, HOA Start $1M+), janitorial inspection (OrangeQC), scrap-yard (ScrapRight, Shon Duty self-funded), independent pharmacy (Datascan family-owned since 1981), dental-lab (Labtrac, DentNode India), museum CMS (CatalogIt), senior-care (AL Advantage), grain/farm (JasBo), tour-operator/outfitter (Adventure Office $870K), campground (Camping.care NL $1.2M), pest control (Pocomos $1.8M), lawn-care (LawnPro, Patrick Cash), auto-repair (Workshop Software AU $2.3M — the rare independent), kids-activity enrollment (Enrolmy NZ grant-funded-not-VC, Enrollsy employee-owned $3M), property-mgmt (Alphaletz UK, tiny £250K angel).
